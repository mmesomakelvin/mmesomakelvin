## How I Work

I care about building tools that are useful beyond the code editor. A good system should be clear for the end user, reliable for the team running it, and documented well enough that people can keep using it after launch.

Most of my projects combine frontend development, data operations, and automation: forms, spreadsheets, payments, emails, dashboards, reminders, and status tracking. I enjoy turning manual processes into working systems that save time, reduce errors, and make data easier to act on.
